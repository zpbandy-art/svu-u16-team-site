This page updates scores in schedule.csv in the zpbandy-art/svu-u16-team-site GitHub repo, using a personal access token. The token is stored only in this browser and sent only to api.github.com.

How do I get a token?
  1. Go to github.com/settings/tokens?type=beta (fine-grained tokens) while signed in as the repo owner.
  2. Click Generate new token.
  3. Under Repository access, choose Only select repositories and pick svu-u16-team-site.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Set an expiration you're comfortable with, generate it, and paste the token above. It's only shown once — copy it right away.
